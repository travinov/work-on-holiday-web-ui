# Проверка кабинета руководителя — 9 сентября 2026

Реализация проверена локально на временных SQLite-базах. Рабочая база, Test-сервер и Production не изменялись.

## Автоматические проверки

Команда из корня проекта с Python окружения проекта:

```sh
python -W ignore::ResourceWarning -m unittest discover -s tests -q
```

Результат: **64 теста пройдены**, в том числе 20 новых сценариев в `tests/test_team_directory.py` и 44 существующих регрессионных проверки отчётов, заявок, ролей и блокировок. Предупреждения ResourceWarning существующего способа использования SQLite соединений подавлены только в тестовой команде.

Проверены повторная миграция, сохранение legacy-ключей/токенов/прав, явное сопоставление записи без почты, отдельные тёзки и вход по почте, запрет самостоятельной выдачи первого токена импортированной записи, атомарный импорт CSV/XLSX, ошибки/циклы/дубли/неизвестные руководители, устаревший предпросмотр и его однократное применение, неизменность отсутствующих строк, пустой руководитель, более 30 уровней, отказ посторонним/заблокированным, отзыв доступа, независимые права администратора, собственные задачи руководителя, запрет изменения чужой заявки, исправленные даты/тексты, множественный выбор, относительные недели, сохранение/обновление/удаление подборок, доступ из другой сессии и изоляция владельцев. Проверен также запрет гостю переписать прежнее ФИО после переименования записи реестром.

`git diff --check` — без ошибок.

## Браузер

Chromium через Playwright, отдельная демонстрационная БД, локальный сервер на 127.0.0.1. Проверены:

- вход по почте и существующему токену;
- прямые подчинённые и все уровни;
- сохранение именованной подборки;
- просмотр подробностей;
- загрузка CSV, предпросмотр и применение с переходом на страницу пользователей.

Визуально просмотрены снимки экранов на ширинах 1280 и 390 пикселей. Локальные файлы (не включены в Git): `output/playwright/manager-desktop.png`, `manager-mobile.png`, `manager-detail-mobile.png`, `roster-preview.png`. Ошибка браузерной консоли только для отсутствующего favicon (404).

Нагрузочная проверка, реальная корпоративная база и серверное развёртывание не выполнялись. Автотесты подтверждают хранение фильтров между отдельными клиентскими сессиями; физический второй компьютер не использовался.
