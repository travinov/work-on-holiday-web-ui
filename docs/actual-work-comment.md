# Комментарий к фактическому времени

В карточке заявки под фактическим временем добавлено необязательное поле комментария. Оно сохраняется существующей кнопкой «Сохранить фактическое время».

- При отсутствии или неполном вводе времени комментарий доступен только для чтения. Ввод корректного интервала открывает редактирование без дополнительного нажатия.
- Плановое время не подставляется автоматически вместо фактического.
- Очистка времени в форме блокирует комментарий, сохраняя введённый текст. Сохранить факт без корректного времени нельзя.
- Статусы «Закрыта» и «Отменена» блокируют редактирование, включая прямую отправку ранее открытой формы и режим администратора. Сохранённый комментарий остаётся видимым. В текущем процессе статус «Закрыта» окончательный; повторное открытие заявки не допускается.
- Существующие ограничения по владельцу заявки и закрытию периода сохраняются. Руководитель видит комментарий в подробностях задачи, администратор — также в списке заявок.
- Изменение статуса и другие правки заявки не стирают комментарий. Старый клиент, не передающий поле комментария, сохраняет прежний текст; явно переданное пустое поле очищает его.

При старте приложения миграция добавляет nullable-поле `actual_work_comment` в `app_request_state`. Старые записи и существующие комментарии при повторном запуске сохраняются. Проверка статуса и запись факта выполняются в одной транзакции с блокировкой записи.

В Chromium на отдельной демонстрационной БД проверены отсутствие времени, ввод, очистка с сохранением текста, повторный ввод, сохранение и чтение после загрузки страницы, перевод в «Закрыта» через экран администратора и блокировка поля после перехода. Визуально проверены компьютерная и мобильная ширина. Скриншоты вне Git: `output/playwright/actual-comment-editable.png`, `actual-comment-closed.png`, `actual-comment-closed-mobile.png`.
