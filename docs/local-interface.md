# Интерфейс в корпоративной сети

Обновление от 22 сентября 2026 года переводит кабинеты сотрудника,
руководителя, администратора и суперпользователя на общую оболочку Tabler 1.5.1.
Сохраняются существующие маршруты, серверные проверки прав, фильтры, выгрузки,
регистрация, импорт оргструктуры и ручной откат.

Цветовая версия `v2026.09.22-racing-green` использует основной оттенок `#004225`
для кнопок, ссылок, активного меню, выбранных дат, полей и информационных сообщений.
Палитра и соответствующие переменные Tabler находятся в начале `static/css/app.css`;
вендорные файлы не изменяются. Белый текст на основной кнопке имеет контраст 11,63:1.

## Что входит в ZIP

- `templates/base.html` — общая навигация, заголовки, сообщения и подключение ресурсов.
- `templates/includes/ui.html` — общие иконки и пункты меню.
- `static/vendor/tabler-1.5.1/` — готовые CSS/JS Tabler, лицензия MIT и манифест SHA-256.
- `static/css/app.css` — сетка, формы, таблицы и адаптация к узкому экрану.
- `static/css/date-time.css` — оформление существующих календарей и полей времени.
- `static/js/app.js`, `static/icons.svg`, `static/favicon.svg` — общие действия и графика.

Браузер получает всё с адреса приложения по `/static/`. Внешние CSS, JavaScript,
иконки, шрифты, CDN и сервер разработки не используются. Иконки календаря внутри
Tabler встроены в CSS как SVG. Шрифт выбирается из системных шрифтов устройства.
Для установки интерфейса не нужны npm, Node.js или сборка frontend на сервере.
Обычные Python-зависимости и требования существующих deploy-скриптов сохраняются.

Исходный пакет: [официальный релиз Tabler 1.5.1](https://github.com/tabler/tabler/releases/tag/%40tabler%2Fcore%401.5.1).
При включении удалены только комментарии sourceMappingURL. Информация об исходном
пакете и его целостности находится в `static/vendor/tabler-1.5.1/manifest.json`.
Иконки навигации приложения хранятся отдельно в локальном SVG-спрайте.

## Обновление

1. Скачайте ZIP нужной версии на корпоративный компьютер и распакуйте его.
2. Запустите штатный `deploy/scripts/update-corporate-server.sh` из новой сборки.
3. После завершения откройте кабинет. CSS/JS получат новый URL с хешем содержимого.

Папка `static/` копируется стандартным rsync вместе с кодом. При обновлении
комплект восстановления включает предыдущую папку ресурсов. Дополнительных
действий для сохранения прежнего оформления не требуется. Откат выполняется
вручную по [инструкции](../deploy/MANUAL_ROLLBACK.md).

При использовании дополнительного reverse proxy путь `/static/` должен
передаваться приложению наравне с остальными маршрутами.

## Проверки

Автоматическая проверка: `venv/bin/python -m unittest discover -s tests -q`.
На дату обновления прошли **125 тестов**, включая локальную раздачу всех ресурсов,
контрольные суммы vendor-файлов, актуальные роли в меню, отзыв доступа, регистрацию,
импорт, фильтры, Excel, заявки и комплекты восстановления.

Браузерная проверка выполняется в Chromium на отдельной временной SQLite-базе:
основные страницы на ширине 1440 и 390 пикселей, меню с клавиатуры, сохранение и
применение фильтра, Excel по текущему списку, календарь и форма заявки, отмена
диалога удаления. Для проверки автономности внешние запросы блокируются;
проверены 11 страниц в двух размерах окна (22 проверки). Внешних запросов,
ошибок JavaScript, ответов HTTP 4xx/5xx и горизонтального выхода страницы
за границы окна не обнаружено. Широкие таблицы прокручиваются внутри карточек.
Временная заявка успешно создана через календарь и форму с перечнем АС.
Скачанные XLSX проверены отдельно: список администратора — одна выбранная
заявка, список руководителя — четыре заявки за заданный период.

Локальные скриншоты и журнал проверки находятся в `output/playwright/` и не входят
в установочный ZIP. Проверка на корпоративном сервере выполняется после установки.
