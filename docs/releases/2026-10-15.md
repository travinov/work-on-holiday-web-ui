# Work on Holiday — 15.10.2026

Версия: `v2026.10.15-calendar-month-ui`.

Сборка для текущего тестового контура (порт 8081).

## Изменения

- Отчёты 1–2 считают уникальные даты фактических выходов за весь календарный месяц эффективной плановой даты, включая её корректировки. Колонка называется «Количество выходов за календарный месяц».
- Комментарий к фактическому времени сохраняется вместе с фактом и виден сотруднику, руководителю и администратору. При незаполненном или некорректном времени поле доступно только для чтения. Закрытые и отменённые заявки защищены от изменения факта и комментария, в том числе администратором.
- На странице пользователей добавлен поиск по ФИО; действия с токенами остаются видимыми.
- Списки заявок, пользователей, задач команды, оргструктуры, предпросмотра импорта, закрытых периодов и отчётов адаптируются к ширине экрана. Дата и время факта не разрываются внутри строки.
- Сохранены интерфейс Racing Green, локальные ресурсы Tabler, экспорт отфильтрованных заявок, регистрация по рабочей почте, импорт оргструктуры и проверяемые комплекты ручного отката перед обновлением.

## Обновление

Распаковать ZIP в локальную папку на корпоративном компьютере и запустить из корня новой сборки:

```bash
deploy/scripts/update-corporate-server.sh
```

Скрипт сохраняет и проверяет комплект для отката перед обновлением. Данные существующего экземпляра сохраняются. Поле `actual_work_comment` добавляется автоматически при инициализации приложения. Ранее выгруженные Excel-файлы нужно сформировать заново, чтобы применился расчёт за календарный месяц.

Публикация GitHub-релиза не устанавливает обновление на корпоративный сервер. Эта сборка не объявлена проверенной Production-сборкой.
